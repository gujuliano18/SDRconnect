# SDRconnect
SDRconnect Web - v1.0.3 · API WebSocket

Para executar a página precisa colocar os arquivos em www se for localhost ou public_html em um servidor web. 
Para alterar a url e porta de conexão acessar arquivo js/core_interface.js
Para alterar o tema escuro para claro trocar o style por style - v1.css - na index.html <link rel="stylesheet" href="/sdr/css/style - v1.css">

To run the page, place the files in the `www` directory (for localhost) or `public_html` (on a web server).
To change the connection URL and port, edit the `js/core_interface.js` file.
To switch from the dark theme to the light theme, change the stylesheet reference in `index.html` from `style.css` to `style - v1.css` (e.g., `<link rel="stylesheet" href="/sdr/css/style - v1.css">`).
